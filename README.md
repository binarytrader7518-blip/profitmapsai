# ProfitMaps AI — affiliate website (static)

Plain HTML/CSS/JS with no build step. Deploy this folder as-is.

## Deploy to Vercel
1. Push this folder to a GitHub repo (or drag it into vercel.com/new).
2. Framework preset: **Other**. Build command: none. Output directory: `.` (root).
3. Assign the domain `profitmapsai.vercel.app`.
4. In Google Search Console and Bing Webmaster Tools, submit `https://profitmapsai.vercel.app/sitemap.xml`.

## Editing
Pages are generated by `build.py` (in the zip next to this folder). Change the content there and run `python3 build.py` to regenerate every page, the sitemap and robots.txt (it writes to ../site, so rename this folder to `site` first, or change OUT in build.py).

## Product images
Product box and screenshot images load unchanged from the seller's image server (media.flexifunnels.io).
To self-host them, download each file into `assets/img/` and change `IMG` in build.py to the matching relative path.
If an image can't load, a branded tile is shown in its place instead of a broken image.
